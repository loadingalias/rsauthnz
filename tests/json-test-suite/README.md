# JSONTestSuite

This directory is test data from <https://github.com/nst/JSONTestSuite>, at commit
`1ef36fa01286573e846ac449e8683f8833c5b26a`, under the MIT license in `LICENSE`. The files are
not changed.

Subset rule: each file of the `test_parsing` directory, which has 95 `y_`, 188 `n_`, and 35 `i_`
cases. The other directories are not here. `tests/json.rs` decodes each file here.
