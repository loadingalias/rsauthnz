# rsauthnz-http

**DO NOT USE IN PRODUCTION.**

rsauthnz-http is the HTTP binding of rsauthnz on the values of the `http` crate: origin and CSRF
checks, cookies, JSON bodies, redirects, safe error responses, and the HTTP message signatures of
an agent. It needs no web framework,
server, or runtime.

rsauthnz-http is in development. Each release can change the API.

rsauthnz-http is a crate of [rsauthnz](https://github.com/loadingalias/rsauthnz).
