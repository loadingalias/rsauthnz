# rsauthnz-conformance

**DO NOT USE IN PRODUCTION.**

rsauthnz-conformance holds the storage conformance of rsauthnz: a test suite for a storage
backend, and a memory backend for tests and examples.

rsauthnz-conformance is in development. Each release can change the API.

rsauthnz-conformance is a crate of [rsauthnz](https://github.com/loadingalias/rsauthnz).
