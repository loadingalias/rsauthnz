# rsauthnz

Authentication and authorization for Rust: passkeys, sessions, and recovery for people, then agent
access that a person owns, limited to named resource actions and a finite time. The application
owns policy, storage, and enforcement.

Status: in development. There is no public API yet.

Develop with `cargo xtask fix`, `cargo xtask test`, and `cargo xtask check`.
